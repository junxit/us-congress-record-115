# ORDER FOR FILING DEADLINE

**Speaking:** McConnell, Mitch (M000355) [R-KY]

```
                       ORDER FOR FILING DEADLINE

  Mr. McCONNELL. Mr. President, I ask unanimous consent that 
notwithstanding rule XXII, the filing deadline for first-degree 
amendments be at 4 p.m. on Monday, July 30, for the measures upon which 
cloture was filed during today's session.
```
